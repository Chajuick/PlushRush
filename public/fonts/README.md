# Self-hosted Korean type

The following fonts are redistributed under the SIL Open Font License 1.1. The complete original license and copyright text is included beside each font. They permit use in commercial applications; fonts must not be sold by themselves. Original TTFs are retained for provenance and future subsets.

- Jua — Copyright 2018 The Jua Project Authors. Source: https://github.com/google/fonts/tree/main/ofl/jua
- Gowun Dodum — Copyright 2021 The Gowun Dodum Project Authors. Source: https://github.com/google/fonts/tree/main/ofl/gowundodum

`Jua-Regular-logo.woff2` is a FontTools-generated subset of Jua for the product title/subtitle, loading at ~9 KB rather than the full 2 MB TTF. Its supported characters are limited to the title and the initial CTA: `달려라! 인형친구들차원의틈너머로 -·꿈속으로출발`. Use it for the logo only; ordinary UI copy should use Gowun Dodum or system UI.

`GowunDodum-Regular.woff2` is the full Gowun Dodum converted from official TTF to WOFF2 (~436 KB), so Korean text outside the product title is supported.

Both files were downloaded from raw.githubusercontent.com/google/fonts with normal TLS verification on 2026-11-06. No runtime request to Google Fonts is required.
