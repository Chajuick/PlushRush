# PlushRush

콩알 같은 3D 공룡 인형과 함께 장애물을 피하는 작은 웹 러닝 게임입니다.

## 실행

Node.js 22 이상이 필요합니다. 처음에는 `npm ci`로 Three.js 의존성을 설치하세요.

```sh
npm run dev
```

기본 포트는 3000입니다. `PORT=3001 npm run dev`로 변경할 수 있습니다.
후방 추적 카메라의 3D 러닝 시안입니다. 점프 버튼으로 시작하고, 좌우 화살표 또는 A/D로 자유 이동, 스페이스·위쪽 화살표로 점프합니다. 모바일에서는 좌우 드래그로 이동하고 위 스와이프로 점프합니다.
충돌하면 다시 시작할 수 있으며 최고 기록은 브라우저에 저장됩니다.

## 확인

```sh
npm run check
```

`dinosaur.js`는 재사용 가능한 3D 봉제 인형 모델과 애니메이션을 정의합니다. 소개 화면의 인형은 드래그해서 회전할 수 있습니다.

캐릭터는 머리와 몸이 하나로 이어진 콩 모양입니다. 러닝 속도·장애물·충돌 수치는 임시 시안 값이며 차원 전환과 RPG 시스템은 아직 구현하지 않았습니다.

`index.html`, `style.css`, `game.js`가 게임을 구성하고 Vite가 개발 서버와 프로덕션 번들링을 제공합니다. `server.mjs`는 초기 시안용으로 남은 파일이며 현재 실행 경로에서는 사용하지 않습니다.

## 인트로

처음 접속하면 `intro.js`의 캐주얼 3D 밤 초원 연출이 재생됩니다. 악몽의 안개와 유령, 인형차원 포탈, 공룡 인형들의 등장 후 현재 스토리보드는 검정 화면·침대→맑은 양 초원→폭풍·유령→인형 구출→로고 순서로 약 8.6초 진행하며 마지막에 게임 이동 버튼이 표시됩니다. 건너뛰기 및 이야기 다시 보기를 지원하며, 인트로 중 러닝은 일시 정지됩니다. 모션 감소 환경에서는 마지막 장면을 표시합니다. 소리 켜기를 선택하면 천둥·별효과 합성음을 사용합니다. 등장 인형은 같은 공룡 모델의 임시 구성입니다.

### 인트로 화면 구성

인형·초원·자수 포탈과 유령은 실시간 Three.js 장면입니다. 잠든 사람은 모바일 가독성을 위한 SVG 전경으로 합성됩니다. 기본 공룡의 둥근 등 돌기, 배 봉제선과 천의 sheen 재질을 공통 모델에 적용했습니다. 생성된 컨셉 이미지는 런타임 배경으로 사용하지 않습니다.

## 프로덕션 빌드·배포

`npm run build` 후 `npm run preview`로 배포용 산출물을 확인합니다. Vercel 연결과 릴리스 절차는 [DEPLOYMENT.md](DEPLOYMENT.md)를 참고하세요. 새 배포는 앱 안에서 알림으로 확인하고 최신 버전 받기를 눌러 적용할 수 있습니다.

새 스토리보드 회귀 검증: `CHROMIUM_PATH=/usr/bin/chromium TEST_BASE_URL=http://127.0.0.1:4173 npm run test:storyboard`. 로고·부제용 폰트의 라이선스와 출처는 `public/fonts/README.md`를 참고하세요.
