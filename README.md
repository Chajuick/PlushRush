# PlushRush

곰 인형과 함께 장애물을 피하는 작은 웹 러닝 게임입니다.

## 실행

Node.js 22 이상이 필요합니다. 외부 패키지 설치는 필요하지 않습니다.

```sh
npm run dev
```

기본 포트는 3000입니다. `PORT=3001 npm run dev`로 변경할 수 있습니다.
스페이스, 위쪽 화살표, 게임 화면 터치 또는 점프 버튼으로 시작하고 점프합니다.
충돌하면 다시 시작할 수 있으며 최고 기록은 브라우저에 저장됩니다.

## 확인

```sh
npm run check
```

`index.html`, `style.css`, `game.js`가 게임을 구성하고 `server.mjs`가 정적 파일을 제공합니다.
